# 🇻🇳 Website Trắc Nghiệm Triết Học Mác - Lênin (1,190 Câu Hỏi)

Website làm trắc nghiệm Triết Học Mác - Lênin trực tuyến miễn phí với đầy đủ **1,190 câu hỏi**, **đáp án chuẩn** và **giải thích chi tiết cho từng câu**.

🌐 **Trải nghiệm ngay tại**: [https://haihoang-ai.github.io/tri-t/](https://haihoang-ai.github.io/tri-t/)

---

## ✨ Tính năng nổi bật

- ⚡ **Tốc độ phản hồi 0ms**: Chạy hoàn toàn trên trình duyệt, không giật lag.
- 💡 **Giải thích chi tiết**: Hiển thị lý giải căn cứ triết học ngay khi chọn đáp án.
- 💾 **Lưu tiến độ cá nhân**: Tự động lưu số câu đã làm, điểm số, tỷ lệ đúng/sai trên thiết bị người dùng qua LocalStorage.
- 🔍 **Tìm kiếm & Bộ lọc**:
  - Tìm nhanh theo từ khóa hoặc số câu (1 - 1190).
  - Lọc theo: *Tất cả*, *Chưa làm*, *Cần ôn lại (Câu làm sai)*, *Đã đánh dấu ⭐*.
- ⌨️ **Phím tắt tiện lợi**: Dùng phím `A`, `B`, `C`, `D` hoặc `1`, `2`, `3`, `4` để chọn đáp án; Phím `⬅️` `➡️` để chuyển câu.
- 🌙 **Giao diện Sáng / Tối (Light & Dark Mode)**.
- 📲 **Hỗ trợ tốt trên Điện thoại & Máy tính**.

---

## 📁 Cấu trúc dữ liệu

- `index.html`: Ứng dụng web đóng gói hoàn chỉnh (Single Page Application).
- `1100_cau_triet_hoc.json`: Dữ liệu 1,190 câu hỏi định dạng JSON.
- `1100_cau_triet_hoc.js`: Dữ liệu module JavaScript.
- `1100_cau_triet_hoc.quiz`: File định dạng `.quiz` text.
